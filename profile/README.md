# Qloudex

**Agentic AI for software, data and cloud automation.**

</div>

Qloudex helps companies and developers automate software development, data platforms and cloud infrastructure tasks using agentic AI, data engineering, RAG pipelines and DevOps tools. We are an early-stage, open-source initiative, building in public.

## What we build

- **Agentic AI for DevOps**: troubleshooting, CI/CD and infrastructure agents
- **DevOps automation**: Kubernetes, Docker, Terraform, Helm, GitOps and monitoring
- **Open source**: everything is public so you can inspect, run and improve it

## Projects

| Project | What it does |
|---|---|
| [kubepilot](https://github.com/Qloudex/kubepilot) | AI-powered Kubernetes and DevOps copilot with RAG, tool-calling, GitOps workflows and observability |
| [SystemMonitoring](https://github.com/Qloudex/SystemMonitoring) | FastAPI service with Prometheus and Grafana, plus AI-driven recommendations |
| [Codewise-CLI](https://github.com/Qloudex/Codewise-CLI) | CLI with a core set of commands to streamline DevOps work |

> These projects are available in the Qloudex organization.
