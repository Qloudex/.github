# Qloudex

### AI & Cloud Engineering Studio

**AI engineering and cloud automation, built for real work.**

[Website](https://qloudex.tech/) · [Discuss a project](https://qloudex.tech/#contact) · [Project hub](https://github.com/Qloudex/qloudex)

</div>

Qloudex is an early-stage engineering studio helping startups and growing teams
build useful AI workflows, reliable cloud infrastructure, and software
integrations—from prototype to practical delivery.

## What we do

- **AI Engineering** — RAG knowledge assistants, task agents, AI workflow
  integration, evaluation, and guardrails.
- **Cloud & DevOps** — CI/CD, containerization, AWS and Azure infrastructure,
  Kubernetes and OpenShift, Terraform, monitoring, and infrastructure reviews.
- **Software & Integrations** — APIs, backend services, internal dashboards,
  workflow automation, and third-party integrations.

## Ways to work with us

| Offering | Starting point |
| --- | --- |
| **AI Workflow Prototype** | Discovery, a focused proof of concept, and an integration plan. |
| **Cloud & DevOps Review** | A scoped read-only review, prioritized recommendations, and an implementation proposal. |
| **Build & Automate** | Custom backend, AI, or DevOps delivery with agreed scope and milestones. |

These are service formats, not fixed packages or guarantees. If you have a
workflow, platform, or integration to discuss, [start a project
conversation](https://qloudex.tech/#contact).

## Open-source engineering

Our public projects make our technical interests and working style inspectable.
They are engineering and experimentation projects—not client case studies.

| Project | What it demonstrates |
| --- | --- |
| [KubePilot](https://github.com/Qloudex/kubepilot) | A Kubernetes operations assistant with runbook retrieval, workload inspection, common-failure diagnosis, and incident reporting. Its local fixture demo is the verified starting point. |
| [SystemMonitoring](https://github.com/Qloudex/SystemMonitoring) | A containerized FastAPI monitoring reference stack with Prometheus metrics and provisioned Grafana dashboards. |
| [Codewise CLI](https://github.com/Qloudex/Codewise-CLI) | A beta Go CLI for Docker, Kubernetes, Helm, deployment, environment, configuration, and file-conversion workflows. |
| [GO-CI-CD](https://github.com/Qloudex/GO-CI-CD) | A learning reference that pairs a small Go application with example OpenShift, Tekton, Buildah, and Argo CD delivery manifests. |

## How we work

**Discover → Scope → Build → Validate → Handover / Iterate**

We favor clear boundaries, reviewable milestones, documented decisions, and
human-reviewed delivery. Open-source work remains separate from private client
work.

## Building toward SaaS

Qloudex plans to productize repeatable solutions discovered through engineering
work. This is a future direction; no Qloudex subscription product is currently
presented here as available for sale.
